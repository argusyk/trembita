# Examples from the textbook “Secrets of Gemini AI” (English edition)

Each file is a code block from the English manuscript, in the order it appears in the text. The fragments are meant to be read alongside the book: some continue an earlier example of the chapter (variables such as `client` or `resp` are defined there). Listings of package modules (`# trembita/...`) are not duplicated – the package itself is in `trembita/` (its comments, prompts and demo data are in Ukrainian; the book's listings are translations).
